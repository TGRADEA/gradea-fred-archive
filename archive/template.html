FRED Archive

The off-box mirror of the GradeA FRED series archive. FRED serves the two ICE BofA OAS series on a rolling ~3-year window, so once an observation ages out, this repository holds the only copy.

Held only here

Observations older than FRED's current OAS window

FRED's cut-off is estimated as three years before this page was built; FRED does not publish the exact boundary. Each OAS series accretes about 262 observations a year, and every one of them eventually crosses into the orange segment.

Revision history

    FRED revises preliminary values after first publication. Each revision lands here as a diff, so git log -p <series>.csv is the vintage record.

    Restore from this mirror

    git clone git@github.com:TGRADEA/gradea_v4.git ~/gradea_v4 export GRADEA_FRED_MIRROR_PATH="$HOME/gradea_v4" cd /path/to/gradea-trading-platform/gradea-backend python scripts/mirror_fred.py --verify-all python scripts/mirror_fred.py --restore-all

    --restore-all refuses to run if verification fails, and refuses to shrink an archive that holds more observations than the mirror. Never force-push this repository: its history is the only record of FRED's revisions.

    Rebuild: python -m gradea_backtest.build_archive
